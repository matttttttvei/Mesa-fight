# Half-Life: Rodent Outbreak — браузерная версия

**Независимый авторский проект, не связанный с Valve Corporation.** Это не официальная игра Valve; проект не поддерживается и не одобрен компанией. Права на Half-Life и связанные товарные знаки принадлежат Valve. Сторонние модели и другие ресурсы принадлежат их правообладателям и используются на условиях соответствующих лицензий.

Игра перенесена с Godot / GDScript на **JavaScript (ES-модули), HTML, CSS и Three.js / WebGL 2**. Godot для запуска браузерной версии не нужен. По запросу пользователя старые Godot-скрипты, сцены, конфигурация проекта и метаданные импорта удалены. Общие модели, текстуры и лицензии сохранены.

## Запуск

Нужен Node.js **20.19+ или 22.12+** и современный настольный браузер с WebGL 2 (Chrome, Edge, Firefox).

```sh
npm install
npm run dev
```

Откройте адрес, указанный в терминале (обычно **http://127.0.0.1:5173**), и нажмите «Начать игру». На Windows PowerShell, если выполнение `npm.ps1` запрещено, используйте **`npm.cmd install`** и **`npm.cmd run dev`**.

Не открывайте `index.html` двойным кликом через `file://`: ES-модулям и загрузчикам моделей нужен HTTP-сервер. После установки зависимостей интернет для игры не требуется. Первичная загрузка использует исходные модели и текстуры (около 110 МБ).

## Сборка для сайта

```sh
npm run build
npm run preview
```

Готовая версия находится в **`dist/`**. Загрузите **всю папку**, включая `dist/assets/`, на статический хостинг с HTTPS. Ресурсы копируются автоматически. Установлен относительный `base`, поэтому игру можно разместить в подпапке сайта. Для публикации исходники и `node_modules/` не нужны.

Ранее был подготовлен комплект **`проекты2/`** для GitHub Pages; при последней очистке этой папки уже не было в рабочем каталоге. Свежую сборку берите из `dist/`: загрузите её содержимое в корень репозитория, добавьте пустой `.nojekyll` и выберите **Settings → Pages → Deploy from a branch → main → / (root)**.

## Управление

| Клавиши | Действие |
|---|---|
| WASD / стрелки, мышь | Движение, обзор |
| ЛКМ | Огонь / удар монтировкой |
| ПКМ | Дуплет дробовика (2 патрона) |
| R | Перезарядка |
| Shift + вперёд | Спринт с расходом стамины |
| Пробел | Прыжок |
| Ctrl / C | Приседание |
| F | Фонарик с зарядом батареи |
| 1–4 / колесо мыши | Смена оружия |
| Esc | Пауза; без захвата мыши — также продолжение |
| Enter / R после смерти | Начать заново |
| F3 | Статистика |
| F6, затем I/K, J/L, U/O | Калибровка поворота оружия по X, Y, Z |

При выходе из захвата мыши, переключении вкладки или потере фокуса игра ставится на паузу. Все игровые таймеры замораживаются. В режиме с захватом возобновляйте игру кнопкой **«Продолжить»**: симуляция запускается после подтверждения Pointer Lock. Запоздалые события старого захвата и отменённого запуска обработаны отдельно. Если встроенный просмотр запрещает Pointer Lock, включите **«Без захвата мыши»** в меню: обзор — перетаскиванием с зажатой средней кнопкой либо **Q / E** (горизонтально) и **PageUp / PageDown** (вертикально).

Рекорд, чувствительность, калибровка и режим без захвата сохраняются в `localStorage`; сохранения Godot автоматически не импортируются. Звук отключён, как в исходнике. Версия рассчитана на клавиатуру и мышь, сенсорного управления нет.

## Что перенесено

- Арена 40 × 40 м: укрытия, колонны, лампы, 10 нор. Мрачное освещение преимущественно от ламп и светящихся бочек, плотный туман и низкая дымка. За четырьмя решётками видны уходящие вдаль коридоры — визуальное расширение, игровые границы не изменены.
- У ламп широкие мягкие переходы света и лёгкое мерцание. Пространственное приближение отражённого света сохраняет читаемость пола, укрытий и врагов в центре без фонарика; заполнение постепенно ослабевает к стенам и потолку.
- От всех семи бочек поднимается угольно-тёмный дым с завихрениями, расширением и рассеиванием. После взрыва новые клубы перестают появляться, оставшиеся уходят вверх за срок до 5,2 секунды; после восстановления дым снова постепенно выходит от крышки. Пауза и экран смерти замораживают дым.
- Свечение бочки находится только внутри единственного маленького отверстия на крышке. Постоянный источник направлен вверх от отверстия; боковые швы и дно не пропускают внутренний свет.
- Движение с разгоном, трением, контролем в воздухе, прыжком и приседанием.
- Стамина: запас 100, расход 22/с при движении спринтом по земле, восстановление 18/с после 0,8 с отдыха. После полного истощения бег доступен с 25; индикатор краснеет до восстановления. Shift стоя, движение назад, приседание и упор в стену запас не расходуют. Пауза замораживает стамину, перезапуск восстанавливает её.
- Здоровье, HEV-броня с поглощением 66% урона, фонарик.
- Монтировка вращается вокруг точки немного ниже середины стержня: верх во время удара уходит от игрока. Пистолет, автоматический SMG, дробовик с дуплетом; боезапас, отдача, перезарядка, смена оружия. Трупы теряют скорость после приземления и больше не скользят бесконечно.
- Мыши, крысы-прыгуны, капибары-танки: погоня, A* с учётом размера тела, обход ящиков и перестроение маршрута после взрыва бочек, атаки, оглушение, прыжки, смерть.
- Крысы ускорены примерно на 10%. Под взглядом игрока сохраняют короткие скачки; после 2,5 секунды накопления засады готовят длинный прыжок с расстояния до 12 м. Только **непрерывный взгляд 0,70 секунды** сбрасывает накопление и отменяет подготовку. Короткие взгляды сохраняют возможность длинного прыжка; уже начавшийся полёт не обрывается. При здоровье 35% или меньше входят в ярость: скорость ×1,35, дальность длинного прыжка до 16 м. Добавлена процедурная анимация лап, головы и хвоста FBX-крысы.
- У мыши светятся глаза, процедурно двигаются лапы, голова и хвост. Деформация рассчитывается на GPU и совпадает с тенью; свечение закреплено на поверхности глаз и гаснет после смерти. Геометрия общая, движение и свечение независимы для каждого экземпляра.
- У капибары 500 HP вместо 250. В свободном проходе она готовит спринт полсекунды, затем разгоняется до 7,8 м/с на 1,6 секунды; рывок можно обойти в сторону, столкновение с препятствием останавливает его. Клип движения во время спринта ускоряется примерно в 2,27 раза, после рывка возвращается к обычному темпу.
- У четырёх ворот исправлены наложение пола, стыки откосов и металлическая рама. Мировая развёртка UV сохраняет одинаковый масштаб кирпича на стенах, перемычках и откосах.
- Волны с исходными формулами количества и интервалов спавна, перерыв 5 секунд. SMG появляется в центре после первой волны, дробовик — после второй.
- Припасы, дроп, взрывные бочки, цепные взрывы и урон по площади. Огненный шар до 7,2 м в диаметре, ударное кольцо и мягкий дым; радиус урона бочек остаётся 6 м. Эффекты переиспользуют заранее созданные объекты и один постоянный свет, шейдеры прогреваются при загрузке — без перекомпиляции при каждом взрыве.
- Янтарный HUD, динамический прицел, следы пуль и кровь, уведомления, пауза, экран смерти, отладка и калибровка.
- Существующие GLTF/FBX-модели и текстуры; резервные процедурные модели на случай ошибки ресурса.

Оптимизация: дым — один instanced draw, максимум 126 переиспользуемых клубов и общий процедурный атлас 256². Статические детали и части моделей ламп объединены по материалу и сектору с сохранением вершин, UV и теней. Переключение фонарика, как и взрывы, теперь меняет интенсивность постоянного света. Разрешение рендера, исходные текстуры и разрешение теней сохранены. Замеры и методика — в `PERFORMANCE.md`.

Это нативная браузерная реализация, **не Web-экспорт движка Godot**. Физика и анимация адаптированы: лёгкие коллизии капсул с боксами вместо Godot Physics, встроенные анимации FBX и процедурное покачивание; освещение, масштаб и некоторые эффекты не пиксель-в-пиксель идентичны оригиналу. Исправлены появление припасов внутри укрытий, переполнение таймеров при перезапуске и неработающий дроп из исходника.

## Структура

| Браузерный файл | Исторический аналог Godot (удалён) |
|---|---|
| `index.html`, `web/styles.css`, `web/hud.js` | `hud.gd`, HUD-сцена |
| `web/main.js`, `web/game.js`, `web/game-state.js` | `main.gd`, `game_state.gd` |
| `web/player.js`, `web/input.js`, `web/physics.js` | `player.gd`, InputMap, Godot Physics |
| `web/weapons.js`, `web/data.js` | `weapon_manager.gd`, `weapon_data.gd`, `rodent_data.gd`, калибровка |
| `web/arena.js`, `web/effects.js`, `web/barrel-smoke.js`, `web/lighting.js` | `arena_builder.gd`, `crate_factory.gd`, бочки, дым и освещение |
| `web/enemy.js`, `web/mouse-visual.js`, `web/spawner.js`, `web/pickup.js` | `rodent.gd`, аниматоры, `spawner.gd`, `pickup.gd` |
| `web/assets.js` | загрузка GLTF/FBX и текстур |

Проверки игровой логики: **`npm test`**.
